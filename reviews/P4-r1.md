### SL-P4-r1-S1: the traceFile guard compares paths as text, so a symlinked `cwd` gets past it

- **Evidence:** `src/recorder/index.mjs:572-575` checks `posix.relative(posix.resolve(cwd), posix.resolve(cwd, opts.traceFile))`, which does not resolve symlinks. A probe on `9d6c1df` used a scratch folder with `real/work` and a link `lnk -> real`. `record(["true"], { cwd: "<s>/lnk/work", traceFile: "<s>/real/work/t.strace" })` was **accepted** (exit 0), so the trace went inside the agent's real work folder. The same trace file with `cwd: "<s>/real/work"` was refused, and so was `<s>/real/work/sub/../t.strace`.
- **Why minor:** the harness picks `traceFile`, and the agent never does. Outside a sandbox the agent can already write the default temp trace folder as the same user (T-7), so this guard is defence in depth, not the boundary.
- **Fix (P5, with T-7):** compare `realpathSync(cwd)` with the realpath of `traceFile`'s parent folder, then add a symlinked-`cwd` case to `tests/integration/security.test.mjs`.
